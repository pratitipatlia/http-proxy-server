# HTTP Proxy Server with Intelligent Caching

## Features
- HTTP request forwarding
- Multithreaded client handling
- Blocked-domain policies
- Intelligent response caching
- TTL-based cache expiry
- Cache hit/miss statistics
- Response-time analysis

## Requirements
- Python 3.10+
- No external packages required initially

## Run
python main.py

## Proxy address
127.0.0.1:8080

## Team responsibilities
- Member 1: Networking, request forwarding, multithreading,
  and domain blocking.
- Member 2: Cache storage, TTL expiry, and analytics.
